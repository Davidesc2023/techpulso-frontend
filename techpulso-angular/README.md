# TechPulso (aplicación Angular)

Esta carpeta es la **Entrega 3** del proyecto: la página de noticias de TechPulso hecha en Angular. La documentación completa (qué hace cada vista, cómo está organizado el código, el despliegue y las limitaciones) está en el [README de la raíz del repositorio](../README.md).

Sitio publicado: https://techpulso-frontend.vercel.app/

## Comandos

Se ejecutan desde esta carpeta (`techpulso-angular`):

```bash
npm install      # instala las dependencias (solo la primera vez)
npm start        # servidor de desarrollo en http://localhost:4200/
npm run build    # versión de producción en dist/techpulso-angular/browser
```

El servidor de desarrollo se recarga solo cada vez que se guarda un archivo.
